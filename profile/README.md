# Jolly Good Desktop Software

Desktop software used to be small enough to understand. You could read the
source of a program in an afternoon, build it with standard tools, and expect
it to behave the same way next year as it did today. Somewhere along the way,
that stopped being the goal.

But the old way still works. This project has one cause: software that is
small, predictable, and lasts. It takes no position on anything else.

## Tenets

**Software should be small.** Every dependency is a cost paid by everyone who
builds, packages, audits or maintains the program. A dependency has to earn
its place, and most do not.

**Software should be predictable.** An interface that keeps changing is an
interface nobody can learn. A program should look and behave the way it did
when you first learned it, unless there is a very good reason to change it.

**Software should be understandable.** Plain C, lean code, and a build that
works without ceremony. If a competent programmer cannot find their way around
a codebase, it is too complicated.

**Software should last.** Good programs do not stop being good because their
platform moved on. Old software worth keeping deserves to be carried forward,
kept buildable and usable on modern systems, without being rewritten into
something else.

**Modern does not mean bloated.** Scalable fonts, Unicode text and modern
display servers are real improvements. Improvements do not imply that bloat
is required. Codebases should remain easy to maintain through simplicity and
intelligent selection of dependencies.

**The user is in charge.** No telemetry, no accounts, no online services
nobody asked for. A program runs on your computer and does what you tell it
to.

**Vision and results over tools.** The tools used to build software are always
changing. Contributions are judged by the result, not by how they were made.

## What this means in practice

Maintain and modernise classic desktop software, and write new software in
the same spirit. Fix what time has broken, adapt to what the modern world
genuinely requires, and leave the rest alone. When in doubt, choose the simpler
option.

If that sounds like the kind of software you miss, you are in the right place.
